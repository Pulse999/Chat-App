## 📖 About The Project

**ChatBuddy** is a modern chat application designed for students, friends, family, and anyone who wants to stay connected.

The application provides users with a simple and engaging environment where they can create an account, personalise their profile, find other users, and communicate through conversations.

ChatBuddy goes beyond basic text messaging by allowing users to personalise their profiles and share media, making conversations more expressive and interactive.

The application was designed with a **mobile-first approach**, allowing users to communicate comfortably across different screen sizes and devices.

## 🚀 Getting Started

### 📋 Prerequisites

Before running ChatBuddy locally, make sure you have:

* **Node.js** installed
* **npm** installed
* **MongoDB** available
* **Git** installed
* A code editor such as **Visual Studio Code**

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/chatbuddy.git
```

---

### 2️⃣ Navigate Into the Project

```bash
cd chatbuddy
```

---

### 3️⃣ Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

---

### 4️⃣ Configure Environment Variables

Create the required `.env` files for the frontend and backend.

Example:

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```

> Never commit private API keys, database credentials, passwords, or other sensitive environment variables to GitHub.

---

### 5️⃣ Start the Backend

```bash
npm run dev
```

---

### 6️⃣ Start the Frontend

Open another terminal:

```bash
cd frontend
npm run dev
```

The application should then be available through the local development URL provided by Vite.
